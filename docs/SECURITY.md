# Безопасность (SECURITY)

## Принципы

1. **Секреты не в коде:** `.env` в `.gitignore`, ключи в `~/.secrets/keys/` (chmod 600)
2. **Секреты не в логах:** `assert_no_secrets_in_text()` блокирует попытку залогировать токены, пароли, ключи
3. **Профили браузера изолированы:** `0700`, вне git, отдельные профили по аккаунтам (Ozon, Avito, WB, почта)
4. **Необратимые действия только с подтверждением:** FSM состояния задачи требуют явного одобрения пользователя в Telegram
5. **Read-only доказательства:** Агент читает артефакты, не может их модифицировать
6. **Минимальные права:** Docker контейнер запускается от `appuser` (UID 1001), `read_only` корень (опционально)

## Что мы НЕ делаем

- ❌ Не храним персональные данные клиентов в репозитории
- ❌ Не обходим капчу автоматически (только ручной вход с телефона)
- ❌ Не делаем автономных списаний, скидок, рекламных рассылок в первом релизе
- ❌ Не используем браузерную автоматизацию против Kwork / FL.ru / Хабр Фриланс

## Что мы делаем

- ✅ Шифруем `.env` через `age` + `.env.age`
- ✅ Ротация логов (30 дней)
- ✅ Audit log для необратимых действий
- ✅ MFA для администраторов (через Telegram 2FA)
- ✅ Принцип минимальных прав, короткие сессии, отзыв доступа при увольнении
- ✅ HTTPS reverse proxy снаружи, PostgreSQL во внутренней сети
- ✅ Ежедневные зашифрованные бэкапы, тест восстановления

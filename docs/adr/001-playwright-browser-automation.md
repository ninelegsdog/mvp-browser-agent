# ADR-001: Выбор Playwright для браузерной автоматизации

## Статус
Принято

## Контекст
Для автоматизации браузера в MVP требуется инструмент, который поддерживает:
- Постоянные профили Chromium с сохранением сессий
- Вход по QR-коду
- Захват скриншотов, видео и trace
- Запуск в headless режиме на сервере
- Работу с современными сайтами (Ozon, Avito, WB)

## Рассмотренные варианты

### Вариант A: Selenium
**Плюсы:**
- Дозревший инструмент с большой экосистемой
- Поддержка всех браузеров
- Широкое сообщество

**Минусы:**
- Нет встроенной поддержки постоянных профилей с сессиями
- Требуются дополнительные инструменты для захвата видео и trace
- Медленнее Playwright

### Вариант B: Puppeteer
**Плюсы:**
- Хорошая поддержка Chrome/Chromium
- Захват скриншотов и видео
- Простой API

**Минусы:**
- Только JavaScript/Node.js (наш стек - Python)
- Нет встроенной поддержки постоянных профилей
- Менее активная разработка по сравнению с Playwright

### Вариант C: Playwright (выбран)
**Плюсы:**
- Поддержка постоянных контекстов с сессиями
- Захват скриншотов, видео и trace из коробки
- Поддержка всех браузеров (Chromium, Firefox, WebKit)
- API на Python
- Быстрая работа
- Активная разработка Microsoft

**Минусы:**
- Требует установки браузеров отдельно
- Менее зрелый, чем Selenium

## Решение
Используем Playwright для браузерной автоматизации.

## Последствия
- Требуется установка браузеров через `playwright install`
- Браузерные провайдеры изолированы через контексты Playwright
- Сессии сохраняются в постоянных профилях с шифрованием на диске

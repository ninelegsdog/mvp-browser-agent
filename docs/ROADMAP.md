# Дорожная карта (ROADMAP)

## Версия 0.1.0 — MVP (текущая)

- [x] Очередь задач: Redis, приоритеты, DLQ, retry-or-DLQ
- [x] Агент-цикл: выбор инструментов (shell/HTTP/файлы/память)
- [x] Браузер: Playwright + постоянный профиль, вход по QR
- [x] Доказательство: скриншот + видео + схема defect.v1
- [x] Outbox: транзакционная таблица, идемпотентная доставка
- [x] Telegram-бот: FSM, кнопки управления, админ whitelist
- [x] Метрики: Prometheus RED, health check
- [x] Docker: multi-stage, UID 1001, docker-compose.prod.yml
- [x] CI: GitHub Actions (lint → test → build)
- [x] Документация: README, RUNBOOK, ARCHITECTURE, DEPLOYMENT, API, SECURITY

## Версия 0.2.0 — Production-ready

- [ ] Page Object Model для Avito и Wildberries
- [ ] Категоризация ошибок в DLQ с уведомлениями
- [ ] Лимиты и антибот: паузы, ротация user-agent, прокси
- [ ] Логирование всех действий в изолированном журнале
- [ ] Unit-тесты покрытие 80%+
- [ ] Mutation testing для критических модулей

## Версия 0.3.0 — Масштабирование

- [ ] Множественные аккаунты клиентов (изоляция профилей)
- [ ] Планировщик отложенных задач (cron-like)
- [ ] Веб-интерфейс для просмотра DLQ и métрик

- [ ] Ежедневный отчёт о состоянии системы

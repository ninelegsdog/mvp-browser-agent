# Руководство по вкладу (CONTRIBUTING)

Спасибо, что хотите помочь сделать этот MVP лучше. Репозиторий подготовлен для показа заказчику в рамках тендера, поэтому качество оформления так же важно, как и качество кода.

## Как внести вклад

1. **Создайте ветку** от `main`: `git checkout -b feature/your-feature`
2. **Внесите изменения** и обязательно запустите проверки:
   ```bash
   ruff check .
   ruff format --check .
   mypy --ignore-missing-imports src/
   pytest --cov=src --cov-fail-under=25
   ```text
3. **Закоммитьте** с соблюдением Conventional Commits:
   ```text
   feat: добавить health check для PostgreSQL
   fix: исправить утечку секрета в логах очереди
   docs: обновить RUNBOOK для развёртывания на VPS
   ```
4. **Отправьте PR** с заполненным шаблоном из `.github/PULL_REQUEST_TEMPLATE.md`

## Правила репозитория

- **Никаких секретов** в коммитах: `.env`, `browser-profile/`, `evidence/` — в `.gitignore`
- **Никакой браузерной автоматизации** против Kwork / FL.ru / Хабр Фриланс
- **Никаких скриптов**, решающих «что продавать и кому» — цены и позиционирование заказчика
- **Все логи** проходят через `assert_no_secrets_in_text()` перед записью

## Процесс ревью

Каждый PR проверяется по чек-листу:
- [ ] Тесты проходят (`pytest`)
- [ ] Линтер чист (`ruff`)
- [ ] Типы проверены (`mypy`)
- [ ] Документация обновлена (`docs/`)
- [ ] CHANGELOG.md обновлён

## Контакты

Вопросы по репозиторию — через Issues с соответствующими шаблонами.  
Вопросы по тендеру — напрямую заказчику.

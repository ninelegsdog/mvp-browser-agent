# Changelog

Все значимые изменения в этом проекте документированы в этом файле.

Формат следует [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/), а версия проекта соответствует [Semantic Versioning](https://semver.org/lang/ru/).

## [0.2.0] — 2026-11-10

### Добавлено
- Реальный браузерный инструмент вместо заглушки: `navigate`, `click`,
  `fill`, `extract`, `evaluate`
- Шифрование профиля браузера (Fernet, ключ в `~/.secrets/browser-profile.key`)
- Изолированные профили по аккаунтам с разными `user_data_dir`
- Не-headless запуск по умолчанию: вход по QR требует видимого окна
- Валидация конфигурации на старте: приложение не поднимается без обязательных
  настроек

## [0.3.0] — 2026-11-11

### Добавлено
- ReAct-цикл: модель выбирает действие в браузере (мысль → действие → результат)
  и пересматривает план после обычного текстового уточнения
- `AutonomousPlanner` с OpenAI-совместимым клиентом, разбор JSON в плоском и
  вложенном виде, типы действий `CLICK/TYPE/NAVIGATE/EXTRACT/FINISH/REMEMBER/TITLE`
- Реальный браузерный инструмент: навигация, клик, ввод текста, извлечение,
  `evaluate` с аргументом, блокировка опасных селекторов
- Подтверждение необратимых действий: `AWAITS_USER` в состоянии задачи,
  `Agent.resume()` выполняет ровно одно подтверждённое действие
- `scripts/preflight.py` — предстартовая проверка конфигурации без импорта
  настроек; `--network` проверяет Redis, PostgreSQL и целевые сайты;
  коды 0/1/2, где 2 — «проверить нечем»
- `scripts/qr_login.py` — ручной вход по QR со скриншотами каждые N секунд и
  честными кодами возврата (0 вход подтверждён / 1 не дождались / 2 нет критерия)
- `docs/CLIENT-START.md` — что нужно от заказчика для старта: каждый пункт с
  командой проверки, включая раздел «чего мы не просим»
- Прокси для браузера (`BROWSER_PROXY`), таймаут входа по QR
  (`QR_LOGIN_TIMEOUT_SECONDS`), адрес прослушивания метрик (`METRICS_HOST`)
- `tests/test_preflight.py`, `tests/test_qr_login.py`, `tests/test_agent.py`,
  `tests/test_tools.py`, `tests/test_browser_tool.py`, `tests/test_metrics.py`,
  `tests/test_smart_locator.py` — 109 тестов

### Изменено
- `BROWSER_HEADLESS` по умолчанию `false`: первый вход по QR требует видимого окна
- Постоянный профиль запускается через `launch_persistent_context`; готовность
  определяется `BrowserSession.is_started`, а не наличием `.browser`
- `Tool` и `Task` вынесены в единый источник истины, `Agent.tools` типизирован
  протоколом `ToolLike`
- `aioredis` заменён на `redis` (aioredis несовместим с Python 3.12 и не
  использовался)
- `aiogram` 3.4.1 → 3.31.0: версия 3.4.1 требовала `aiohttp~=3.9`, из-за чего
  установка зависимостей падала в чистом окружении
- `aiohttp` 3.11.14 → 3.14.5: 3.11.14 отозвана (regression), установка
  предупреждала о yanked-версии
- `admin_only` и `admin_only_callback` обёрнуты в `functools.wraps` — aiogram 3
  строит внедрение `message`/`state` по сигнатуре обработчика

### Изменено (шифрование профиля)
- Шифрование профиля по умолчанию выключено (`BROWSER_PROFILE_ENCRYPTION`):
  защита кабинета — права `0700` и профиль вне git, шифрование нужно для
  бэкапа и переноса
- Шифрование и дешифрование идут в отдельном потоке (`asyncio.to_thread`) —
  раньше закрытие браузера блокировало цикл событий на минуты
- Маркер `.profile-encrypted` пишется последним и удаляется первым: профиль
  либо зашифрован целиком, либо не зашифрован, «наполовину» не бывает
- Симлинки профиля не шифруются (их нельзя зашифровать на месте)

### Исправлено
- `BrowserSession.navigate()` переходит в текущей странице: раньше каждый шаг
  оставлял открытую вкладку, а `check_session()` смотрел на старую страницу
- E2E-тесты браузера больше не ходят в интернет: страница отдаётся из
  локального файла, проверка сайтов — на локальный адрес и закрытый порт
- Подтверждённое действие больше не теряется: `confirm_action()` не очищает
  отложенный шаг, `resume()` выполняет его ровно один раз (ошибка была видна
  только на стыке двух функций, поэтому добавлен тест на этот путь)
- Кнопка «Продолжить» не выполняет неподтверждённое действие
- Голосовое сообщение получает честный отказ вместо выдуманного текста задачи
- `Agent.run()` больше не перезаписывает `AWAITS_USER` на `DONE`
- `FINISH` не требует вызова инструмента и завершает задачу корректно
- Устранены `except: pass` в метриках и `raise e` в браузере
- Проверка `tracemalloc.is_tracing()` вместо повторного `start()`

## [0.1.0] — 2026-11-10

### Добавлено
- Очередь задач на Redis с приоритетами high/med/low, DLQ, retry-or-DLQ
- Агент-цикл с выбором инструментов (shell/HTTP/файлы/память/браузер)
- Браузер с постоянным профилем Chromium, вход по QR, профиль 0700 вне git
- Доказательство результата: скриншот + видео + схема defect.v1, read-only доступ
- Транзакционный outbox в PostgreSQL с идемпотентной доставкой
- Telegram-бот на aiogram 3 с FSM состояниями, кнопками стоп/отменить/продолжить
- Белый список BOT_ADMIN_ID для управления ботом
- Prometheus RED метрики, эндпоинты /health и /metrics
- Health check с проверкой Redis и PostgreSQL
- Docker multi-stage build, пользователь UID 1001, docker-compose.prod.yml
- GitHub Actions CI (lint → test → build), pre-commit хуки
- Документация: ARCHITECTURE, DEPLOYMENT, API, SECURITY, ROADMAP, RUNBOOK
- Тесты: 30 юнит-тестов, покрытие 45%

### Безопасность
- assert_no_secrets_in_text — защита от утечек секретов в логах
- .env в .gitignore, пример в .env.example
- Профили браузера в .gitignore, права 0700

### Исправлено
- Исправлена ошибка импорта aioredis на redis.asyncio (совместимость с Python 3.12)
- Исправлены корейские символы в документации
- Исправлены опечатки в русскоязычных строках
